# Contributing Guidelines

Thank you for your interest in contributing to this sample code.

## Before you contribute

- All contributions must comply with the MIT-0 license.
- By submitting a pull request, you agree that your contributions will be licensed under the MIT-0 License.
- This is a sample code repository tied to the accompanying blog post. Major feature requests may not align with the sample's scope.

## Security

If you discover a security vulnerability, please email security@amazon.com rather than opening a public issue.

## Code of Conduct

This project has adopted the AWS Community Code of Conduct. For more information see the [Code of Conduct FAQ](https://aws.amazon.com/codeofconduct-faq/) or contact opensource-codeofconduct@amazon.com with any additional questions or comments.
